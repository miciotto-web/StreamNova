🎬 STREAMNOVA 1.1.0 È DISPONIBILE!

La nuova versione porta il motore HTTP al livello successivo e chiude le correzioni TV/D-pad rimaste in coda dopo la 1.0.10.

✨ NOVITÀ PRINCIPALI

🌐 Nuovi provider HTTP
• Altadefinizione: nuovo provider basato sul player vidxgo, con ricerca per IMDb ID e rinnovo automatico del token HLS durante la riproduzione.
• StreamingCommunity: risolve i flussi tramite l'endpoint pubblico vidxgo (la pagina HTML risponde 403).
• CB01 / CB01 Uno: domini aggiornati (cb01one.uno come canonico, con alias di fallback).

⚙️ Scelta del provider
• Provider HTTP principale: Automatico oppure un provider specifico.
• Solo provider scelto: nessun fallback se il provider non risponde (disattivabile).
• Provider sperimentali: spenti per default; in Automatico restano attivi solo VixSrc e Altadefinizione. Il provider scelto manualmente viene sempre eseguito.
• Le sorgenti del provider preferito restano in cima al selettore.

📺 TV e D-pad
• Badge di ordinamento Film/Serie TV: Recenti, Per Valutazione, Popolari.
• Griglie senza sobbalzi: LEFT/RIGHT non muovono più il catalogo in verticale.
• Fix crash D-pad nel selettore avatar.

🔧 Altri fix
• Una scrittura OpenSubtitles in volo non può più sovrascrivere la rimozione della chiave.
• Regole R8 per i payload vidxgo: parsing stabile anche nella release minificata.
